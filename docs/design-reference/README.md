# Design reference

Разбор дизайн-системы Wispr Flow (токены, типографика, компоненты, анимации, сетка).
Источник: локальный архив `~/Downloads/wr/sites/wisprflow/`, помеченный автором
как "Design Specimen Archive" — образовательный референс, не продакшн-ассеты.

Используется как **ориентир для собственного оверлея**, а не для копирования
интерфейса один в один. Репозиторий приватный.
