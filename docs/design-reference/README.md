# Design reference

Токены, типографика, компоненты, анимации, сетка — как **ориентир для
собственного оверлея**.

## Откуда это на самом деле

Раньше здесь было написано «разбор дизайн-системы Wispr Flow». Это неверно,
и правка важна по существу.

Источник — локальный архив `~/Downloads/wr/sites/wisprflow/`. Он не выкачка
сайта wisprflow.ai. Каждый файл несёт дисклеймер:

> Настоящий архив (Design Specimen Archive, vol. 03) […] Материалы архива
> являются референсами и демонстрацией возможностей генеративных AI-моделей
> […] Архив не претендует на полноту, точность или актуальность извлечённых
> данных.

То есть это **воссоздание сайта нейросетью**, а не сам сайт. Проверка
подтверждает расхождения с живым продуктом: 30+ языков против 100+,
macOS 13+ против 12+, цена $12 против $15.

## Что из этого следует

1. **Цвета и токены ниже — не палитра Wispr Flow.** Считать их
   восстановленными значениями чужой дизайн-системы нельзя. Это просто
   палитра, которая нам подошла, неизвестного происхождения.
2. **Как ориентир файлы годятся ровно так же, как и раньше.** Оверлей
   рисуется свой, один в один ничего не копируется — а для «с чего начать»
   источник и не обязан быть подлинным.
3. **Фактические утверждения о продукте отсюда брать нельзя.** Ни цифры, ни
   формулировки, ни описания механики. Для этого есть
   `docs/research/wispr-reverse-engineering.md`, где живой сайт и
   документация отделены от архива.
