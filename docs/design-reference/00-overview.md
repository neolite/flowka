# Wispr Flow — паспорт сайта (design system overview)

> Источник: https://wisprflow.ai/?ref=producthunt · дата извлечения: 2026-07-29

## Продукт

Wispr Flow (бренд «Flow») — AI voice-to-text диктовка: превращает сбивчивую устную
речь в чистый, отформатированный текст в любом приложении. Ключевое обещание —
«4x faster than typing» (220 wpm голосом против 45 wpm на клавиатуре). Платформы:
Mac, Windows, iPhone, Android.

## Вайб

Тёплый «аналоговый» light-theme: кремово-лимонный фон (#ffffeb, «lumen»),
глубокий тёмно-бирюзовый (#034f46, «fathom») как главный тёмный цвет вместо
чёрного, лиловый (#f0d7ff, «dawn») как акцент кнопок. Крупные serif-заголовки
(EB Garamond) с экстремально плотным трекингом и line-height 0.85, гротеск
Figtree для UI. Фирменный приём — «речевой поток»: длинные бегущие строки
реальной диктовки, ползущие по изогнутым SVG-траекториям (сырой текст →
отполированный текст). Пиллы-табы повёрнуты на −4°, карточки — крупные радиусы
2–5rem, границы 2px твёрдым тёмным цветом, «липкие» hover-нажатия scale(.98).

## Тема и доминирующие цвета

- Тема: **светлая** (тёмные секции строятся на fathom #034f46 и vast #1a1a1a).
- Доминирующие: lumen #ffffeb (фон), vast #1a1a1a (текст/бордеры), fathom #034f46
  (тёмные панели), dawn #f0d7ff (кнопки/акценты), glow #ffa946 (жёлто-оранжевый CTA).

## Стек

- **Webflow** (cdn.prod.website-files.com, проект `682f84b3838c89f8ff7667db`),
  единый минифицированный CSS 583 КБ + 20 inline `<style>`-блоков.
- Анимации: **GSAP 3.15** (+ DrawSVGPlugin, MotionPathHelper), **Lottie**
  (hero-анимация «toasts»), **Splide** + splide-extension-auto-scroll
  (marquee-карусель отзывов), Swiper 8, Finsweet Attributes.
- Прочее: Usercentrics CMP, Typeform embed, ahrefs analytics.

## Способ добычи

Обычный `curl -sL` c desktop User-Agent: HTML 229 КБ (полный серверный рендер
Webflow, не JS-шелл), CSS скачан по `<link rel="stylesheet">`. Фолбэки
(crawl4ai/firecrawl) не понадобились. Просмотрена главная страница целиком.

## Киллер-фичи дизайна (что делает сайт узнаваемым)

1. **SVG text-path marquee в hero**: два изогнутых «потока речи» — сырой
   (полупрозрачный, weight 400, с «umm…», повторами слов) и чистый (белый
   weight 600 на жирной тёмной кривой) — метафора продукта. `<animate>` по `x`,
   35s / 100s, infinite.
2. **H1 с «выцветшей» частью**: «Don’t type, » в #8a8a80 + «just speak» полным
   цветом; EB Garamond 7.5rem, letter-spacing −0.05em, line-height 0.85.
3. **Пиллы-табы use-cases** с rotate(−4deg) в активном состоянии и «прыгающим»
   margin на hover.
4. **Секция-сравнение скоростей**: «Keyboard · 45 wpm» (серый прямой marquee)
   против «Flow · 220 wpm» (белый marquee на тёмной фото-панели).
5. **Masonry-лента отзывов** на Splide auto-scroll: карточки 26rem/46rem с
   цветными подложками (glow/dawn/fathom/signal/flare) и статистикой поверх
   фото с градиентом.
6. **Твёрдые тени и обводки**: `2px 2px 0 0 #1a1a1a`, бордеры 2px, радиусы
   секций до 5rem — «бумажно-наклейчатый» стиль.
7. **Ask-AI блок**: рамка 4px сверху+справа, uppercase-заголовок Figtree 700,
   кнопки «Ask ChatGPT / Ask Claude / Ask Perplexity».
