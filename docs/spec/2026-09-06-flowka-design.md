# Flowka — локальная диктовка для macOS

**Дата:** 2026-09-06
**Статус:** дизайн согласован, реализация начата
**База:** форк [sam-pop/WhisperDictation](https://github.com/sam-pop/WhisperDictation) (MIT)

---

## 1. Задача

Инструмент ежедневного личного использования: зажал клавишу → сказал → отпустил →
текст появился в активном поле ввода любого приложения. Полностью офлайн.

**Критерий успеха — не демо, а то, что автор пользуется этим каждый день.**

### Отличие от существующих решений

Все четыре найденных open-source аналога (WhisperDictation, OpenFlow, whisper-local,
OpenWhisper) решают английскую диктовку. Целевой режим здесь другой и более трудный:

> **русский с вкраплениями латиницы**: «сделай pull request», «это effector store»,
> «задеплой на staging».

Whisper склонен транслитерировать такие термины в кириллицу («пул реквест»). Возврат
канонического написания — основная ценность проекта, а не сам факт распознавания.

  доверять нельзя: он вернул ноль `public`-деклараций вообще, включая заведомо
  существующие, — значит сломался сам поиск. **На выбор это не влияет:** API
  Apple привязан к одной локали и потому дисквалифицирован независимо от наличия.
- Латентность turbo на M1 Pro, сохранность латиницы, поведение вставки в
  Electron-приложениях и терминалах — всё это подлежит замеру, оценок в спеке нет.

## 3. Архитектура

Ключевое упрощение: **push-to-talk превращает потоковую задачу в пакетную.**
Отпускание клавиши и есть конец фразы. Не нужны VAD, endpointing и частичные
гипотезы — это убирает самую сложную половину проекта.

```
Right ⌥ (hold)
   │
   ├─► HotkeyMonitor ──► AudioCapture (16 kHz mono)
   │                          │
   │   (release)              ▼
   └────────────────►  WhisperBridge  ── ggml-large-v3-turbo, language="ru"
                              │           + initial_prompt (≤224 токена)
                              ▼
                       TextPipeline
                       ├─ GlossaryCleaner   (детерминированные замены)
                       └─ TextCorrector     (только для en, на ru отключён)
                              │
                              ▼
                       TextInjector  ── NSPasteboard + ⌘V, восстановление буфера
                              │
                              ▼
                       Активное приложение
```

### Слои и границы

| Модуль | Ответственность | Зависимости |
|---|---|---|
| `HotkeyMonitor` | Right ⌥ hold/release | AppKit |
| `AudioCapture` | микрофон → PCM 16 kHz | AVFoundation |
| `WhisperBridge` | PCM → сырой текст | whisper.cpp |
| `GlossaryCleaner` | транслит → канон | **только Foundation** |
| `TextInjector` | текст → активное приложение | AppKit, CoreGraphics |
| `OverlayPanel` | индикация состояния | SwiftUI, неактивирующаяся |

`GlossaryCleaner` намеренно не зависит от платформы: это единственный модуль, который
можно писать и тестировать вне macOS.

## 4. Возврат латиницы — двухуровневая схема

Оба консультанта (advisor и Codex) независимо пришли к одному выводу: **LLM здесь
неуместна как обязательный слой.** Она способна восстановить термин, но столь же
способна переписать смысл, имя или идентификатор, а по одной испорченной строке
исходное написание порой неоднозначно.

**Уровень 1 — `initial_prompt` в whisper.cpp.** Строка со смешанными скриптами
смещает декодер в сторону сохранения латиницы. Нулевая латентность, ноль зависимостей.

> Обсуждали pull request и merge в master. Это effector store, проверь useUnit.
> Задеплой на staging. Посмотри в Figma.

**Ограничение, зафиксировать в коде:** whisper.cpp принимает промпт в **токенах**
(порядка 224), а не в словах. В базе заложен бюджет 700 слов — это ошибка, на
кириллице токенов на символ заметно больше. Промпт обязан обрезаться по токенам.

**Уровень 2 — словарь явных замен.** Детерминированный, по границам слов, длинные
фразы имеют приоритет над короткими:

```
пул реквест   → pull request
эффектор      → effector
юз юнит       → useUnit
стейджинг     → staging
```

Неоднозначные одиночные слова (`пул`) глобально не заменяются. Исходная транскрипция
сохраняется, чтобы замену можно было откатить.

**Уровень 3 (не в v1) — `TextCleaner` через Ollama.** Протокол объявляется сразу,
реализация откладывается. Причина отказа в v1: бюджет 800 мс на ответ Qwen ничем не
подтверждён, а после холодного старта тем более. Таймаут превратил бы функцию в
постоянно не срабатывающую.

## 5. Вставка текста

**Основной путь: `NSPasteboard` + синтетический ⌘V.** Apple прямо документирует, что
приложение вправе проигнорировать Unicode-строку синтетического события клавиатуры,
поэтому `CGEventKeyboardSetUnicodeString` (используемый в базе) для длинной кириллицы,
Electron-приложений и терминалов ненадёжен.

Обязательные детали, каждая — из реального класса отказов:

- дождаться отпускания модификаторов перед отправкой ⌘V, иначе зажатый ⌥ исказит вставку;
- проверить, что целевое приложение то же, что было в момент начала записи;
- восстанавливать прежний буфер **только если `changeCount` не изменился** после нашей записи;
- задержка восстановления — эвристика: отправка ⌘V не означает, что приложение уже прочитало буфер;
- **не запускать unicode-фолбэк автоматически** — риск двойной вставки. Только явная команда «вставить другим способом»;
- в терминале не добавлять Enter.

## 6. Разрешения и подпись

TCC привязывает выданные разрешения к идентичности подписи кода. Ad-hoc подпись
(`codesign --sign -`, как в базе) меняет идентичность при каждой пересборке, и macOS
молча теряет Accessibility и Microphone. Это классический провал, съедающий полдня.

**Решение:** стабильный Development-сертификат, постоянный bundle ID, постоянный путь
установки — с первой же сборки. Подпись не отменяет необходимости проверять
разрешения после пересборки, но делает их сохраняемыми.

## 7. UI

Одна аккуратная капсула-оверлей, а не клон интерфейса Wispr. Состояния: ожидание,
запись (мягкая анимация уровня звука), обработка, ошибка. Панель **неактивирующаяся**
(`.nonactivatingPanel`) — иначе она заберёт фокус и вставлять будет некуда.

Ориентир — разобранные токены в `docs/design-reference/` (цвета, типографика,
тайминги анимаций). Берём систему, не копируем экраны.

Дополнительно к надёжности повседневного использования: отмена записи, корректная
обработка тишины, кнопка «скопировать последний результат».

## 10. План проверки

Решение о модели принимается **по замерам, не по мнению**: 30–50 собственных записей
(короткие команды, отрезки 30–60 секунд, термины внутри русской фразы). Метрики:
доля сохранённых латинских терминов и p95 задержки «отпустил → вставилось», при
обычном наборе открытых рабочих приложений.

Кандидаты: `large-v3-turbo` (основной), `large-v3` (контроль качества),
`medium` (запасной при нехватке памяти). Turbo мультиязычный — но у него 4 слоя
декодера вместо 32, и гарантии сохранения латиницы он не даёт.
